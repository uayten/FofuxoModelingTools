# Fofuxo Modeling Tools

Blender add-on with tools that speed up modeling and export: an Angle checkbox
in the Mirror modifier that mirrors across a plane tilted 45°, a Merge
Collection modifier that joins a whole collection into a single mesh, and a
Spherical Bend modifier that bends a flat mesh into a vault.

In development.
